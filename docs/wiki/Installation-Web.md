# NeoFile web desk

The web desk is the browser copy of the editor. The address is [himanshu-5680.github.io/NeoFile/desk/](https://himanshu-5680.github.io/NeoFile/desk/).

It is not the native iOS app, not the Android APK, and not a store listing. The page title is "NeoFile web desk".

## First open and offline use

The first open needs a network connection so the browser can download the page and its scripts. After that download, the saved copy can open with no network. The browser, especially iOS, can delete that saved copy later. Open the page once while online to save it again.

Files stay on the device. The web desk does not upload them. Picking a file uses the browser's file picker.

## Add to Home Screen

On an iPhone, open the page in Safari, choose Share, then Add to Home Screen. The icon is the web app. Android Chrome can install the same page from the browser menu. A computer can keep using the page in a tab.

## What this does not do

The unsigned IPA is a separate file. iOS will not install that IPA from Files, and this project has no free path that installs the native iOS package on every phone. The web desk does not add that path.
