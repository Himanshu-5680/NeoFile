# Architecture

NeoFile is one web UI in three shells. The UI does not talk to a NeoFile server.

```
apps/web            React, TypeScript, Vite
apps/web/android    Capacitor Android project and the NeoFile Java plugin
apps/web/ios        Capacitor iOS project
apps/desktop        Tauri 2 shell
packages/core       parsing, snapshots, search, theme, sanitizer, tests
website             static project site
```

## Shared UI

`apps/web` renders the desk: tabs, the folder tree, the editor host, and the viewers. CodeMirror 6 edits text. A small grid edits CSV. SheetJS reads and writes spreadsheet values. PDF.js draws PDFs. Mammoth turns docx into HTML. JSZip and a small XML reader preview pptx. Those libraries are npm dependencies loaded in separate chunks. They are not copied into git.

`packages/core` is the code that has to stay honest about formats: file detection, CSV, search, theme, undo history, snapshot records, the pptx text extract, and `sanitizeHtml`. Vitest covers it. The HTML sanitizer is an allow-list. It drops scripts, event handlers, and remote images before Office preview HTML reaches the page.

CSV parsing and spreadsheet reads run in `apps/web/src/workers/heavy.worker.ts` so a large file does not freeze the window. If the worker cannot start, the client falls back to the main thread.

Recent files and snapshots use IndexedDB (`packages/core/src/idb.ts`). Tests use `fake-indexeddb`. There is no sync protocol.

## Desktop

`apps/desktop` is a Tauri 2 app. The window loads the built web UI from `apps/web/dist`. Rust code in `apps/desktop/src-tauri/src/lib.rs` creates the tray menu and hides the window on close when the tray exists.

File dialogs and filesystem access go through the Tauri plugins. The capability file allows read and write inside the home, download, document, and desktop directories. The content security policy does not allow ordinary web requests.

## Android

Capacitor hosts the same `dist` output. `NeoFilePlugin.java` implements the share inbox, the file and folder pickers, and saving through the Android storage APIs. The activity accepts `ACTION_SEND` and `ACTION_SEND_MULTIPLE`. `AndroidManifest.xml` removes `INTERNET` and disables cleartext traffic.

Release APKs are signed either with the GitHub Actions keystore secrets or with a throwaway key generated by `scripts/build-android.sh` when those secrets are missing.

## iOS

The iOS project is the Capacitor shell. `scripts/build-ios-unsigned.sh` builds with `CODE_SIGNING_ALLOWED=NO` and zips `Payload/App.app` into an IPA. AltStore or Sideloadly re-signs that IPA. The repository does not contain a provisioning profile.

## Website

`website/` is a static neo-brutalist page. Fonts are files in `website/fonts`. GitHub Pages publishes that directory as-is. It is not the app.

## What is deliberately missing

There is no account, no remote font, and no telemetry endpoint. Formula recalculation, Word editing, and PowerPoint layout are not implemented. Those limits are shown in the UI rather than implied by an edit button that does not write the format.
